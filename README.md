# ShiningLion_WelLink_Project
샤이닝라이언(인턴): 웰링크 프로젝트

광고주 관점으로 재설계한 웰링크 SaaS 대시보드 개선안

# OverView
웰링크는 인플루언서 캠페인을 운영하는 광고주용 SaaS 관리자 대시보드를 제공하고 있었습니다.
그러나 기존 대시보드는 주요 지표를 제공하고 있었지만, 광고주가 실제 비즈니스 성과와 다음 액션을 판단하기 어려운 한계가 있었습니다.
이에 광고주 관점에서 기존 한계를 분석하고, KPI 정의·가상 데이터 모델·Tableau 대시보드를 설계해 대시보드 개선안을 제안했습니다.
